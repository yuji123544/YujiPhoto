YujiPhoto app icon (photocraft.svg, photocraft-small.svg and every file derived from them in
this directory: photocraft-1024.png, photocraft.icns, photocraft.ico, hicolor/).

Regenerate every file here with: node roblox/scripts/make-icon.mjs
(packaging/icons.sh is upstream's script for their own master and is not used by this fork.)
